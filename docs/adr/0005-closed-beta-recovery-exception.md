# Accept the free-plan recovery window for the closed beta

The Mexico-only invitation beta will temporarily use Neon's six-hour restore
history without protected-branch or scheduled-snapshot support because the
current organization remains on `free_v2`. This is an explicit reduction from
the preferred seven-day history and daily 30-day snapshot design; it must be
removed before widening enrollment or storing finance data that cannot be
reconstructed by a beta user.
